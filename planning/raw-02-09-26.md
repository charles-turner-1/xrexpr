# Interned IR v2: structure-preserving, name-only interning with `InternedVal`

## Context

The interned IR already exists (`src/xrexpr/interned.py`): one singleton `Interner`, 13
sibling `Interned*` records, a total `intern`/`deintern` pair with `assert_never`, and a
green hypothesis round-trip. But its interning is **blind and lossy**: it recurses into
every payload and interns each hashable leaf to a bare `int`, collapsing whole `Indexer`
and `ChunkSpec` variants into a single **opaque handle**.

That is wrong for the actual goal. **The Rust side does the reasoning**, so it needs the
closed value sum-types (`Indexer`, `ChunkSpec`) as *structure* — they exist precisely to
map onto Rust enums. Opaque handles destroy exactly what the reasoner manipulates: slice
bound / position arithmetic (`optimize._compose_slice`, `_index_sequence`), `drops_dim`
dispatch, and `Auto | ByteSize | BlockSeq` chunk-kind checks (`_pushable_rechunk`). It also
conflates a *name* handle with a *literal* `int` value (a position, a block size), so a
reader can't tell which is which.

**Outcome:** interning becomes a *name-only relabeling* that preserves structure. A handle
is a distinct type, `InternedVal`, never a bare `int`; positions, bounds, sizes, labels and
the `Indexer`/`ChunkSpec` wrappers are left intact; only genuine *name atoms* (dim and
variable names) become `InternedVal`. Rust extracts each interned node straight into a
typed struct — enums for the value sums, `InternedVal` handles for names. Round-trip stays
total and exact.

## Approach

### 1. `InternedVal` newtype (`src/xrexpr/interner.py`)

```python
@final
@dataclass(frozen=True)
class InternedVal:
    """A name relabeled to an interner handle — distinct from a literal ``int`` value."""
    handle: int
```

One field, frozen, hashable. `_iname(x) -> InternedVal(Interner()(x))` and
`_dename(v) -> Interner()[v.handle]` are the leaf converters. Being a distinct type is the
whole point: a name handle can never be mistaken for a position or a chunk size.

### 2. Selective, structure-preserving interning (`src/xrexpr/interned.py`)

Replace the blind recursive `_intern`/`_deintern`. Interning is now **per-field**, driven
by which fields hold names — the modelled metadata the optimiser/Rust reason about:

- **Relabel to `InternedVal`:** `consumes`, `dims`, `variables`, `group_dim`, `new_dim`,
  `weight_dims`; the **keys** of `indexer`, `chunks`, `window`, `mapping` (and `mapping`
  values, which are names too).
- **Keep intact:** the `Indexer` and `ChunkSpec` variant *values* — and every value atom
  they carry (positions, bounds, block sizes, byte strings, labels, bools), plus `window`
  *values* (sizes). The one name buried inside a value is `Advanced.dims`; a small
  `_intern_indexer` relabels just that and returns the variant unchanged otherwise (moot on
  live plans — an `Advanced` select is recorded `Opaque` — but kept for totality).
- **Leave verbatim:** `args`/`kwargs` — see §3.

`intern`/`deintern` keep their per-op `match` + `assert_never` shape; each arm calls the
name helpers on its name fields and passes values through. `deintern` still rebuilds through
the fluent constructors, so `__post_init__` re-derivation is unchanged.

### 3. Lock down the reasoning surface; quarantine the replay payload

The `Any`s come from the verbatim `args`/`kwargs`. They can't be dropped — `lower._emit_node`
replays by re-invoking `getattr(ds, name)(*args, **kwargs)` **verbatim**, and they carry more
than the modelled fields (`mean(dim='time', skipna=False)` — `skipna` lives nowhere else). So
instead of leaving the reasoner to *parse* them, **materialize every reasoning field that
would otherwise require reading the opaque payload** into a typed field:

- `InternedReduce.keepdims: bool` (from `kwargs`),
- `InternedProject.single: bool` (from `args[0]`'s type),
- `InternedRechunk.uniform: ChunkSpec | None` (from `args[0]`).

These are computed at intern time from the fluent node's own derivation (`op.keepdims`, …),
so they cannot disagree; `deintern` ignores them and rebuilds from the verbatim payload, so
they carry no round-trip risk — they exist purely so **Rust never parses `args`/`kwargs`**.
`Select.consumes` is *not* materialized: it follows from the typed `indexer` via `drops_dim`,
which Rust implements regardless.

`args`/`kwargs` remain on the record as the **one deliberate loosely-typed slot** — the
Python replay header, which the Rust reasoning struct does not extract. (If we later want a
literally zero-`Any` record, the alternative is to lift the replay header out of the interned
node entirely and keep it Python-side, making the interned form a one-way reasoning view
rather than a self-contained round-trippable op — a bigger change, noted not taken.)

### 4. `Interned*` record field types

Name fields become `InternedVal`; value fields keep the real sum-types; reasoning flags are
materialized; `args`/`kwargs` are the quarantined replay header:

```python
@dataclass(frozen=True)
class InternedReduce:
    name: str
    consumes: frozenset[InternedVal] | AllDims = frozenset()
    keepdims: bool = False
    args: tuple[Any, ...] = ()                                         # replay header
    kwargs: frozendict[str, Any] = field(default_factory=frozendict)   # replay header

@dataclass(frozen=True)
class InternedSelect:
    name: Literal["isel", "sel"]
    indexer: frozendict[InternedVal, Indexer] = field(default_factory=frozendict)
    args: tuple[Any, ...] = ()
    kwargs: frozendict[str, Any] = field(default_factory=frozendict)
```

`InternedRechunk`: `chunks: frozendict[InternedVal, ChunkSpec]`, `uniform: ChunkSpec | None`.
`InternedProject`: `variables: tuple[InternedVal, ...]`, `single: bool`.
`InternedElementwise`/`InternedOpaque`/`InternedContextOpen` have no name/reasoning fields —
just the replay header.

### 5. Align schema interning to `InternedVal` (`src/xrexpr/schema.py`)

`SchemaState.to_interned` currently produces bare-`int` names (`SchemaState[int]`). Change
it to `SchemaState[InternedVal]` — names → `InternedVal`, `sizes` **values** stay bare
`int` (they are extents, not names). `from_interned` mirrors. This gives one handle
representation across nodes and schema (and is a precondition for the deferred
optimise-on-interned work).

### 6. Tests

- Keep the ops round-trip property test green (`deintern(intern(op)) == op`).
- Add targeted assertions that interning is *selective*: a `Select(indexer={"time":
  Scalar(3)})` interns to `indexer={InternedVal(_): Scalar(3)}` — key wrapped, `Scalar(3)`
  and its position **unchanged**; a `Rechunk` keeps its `ChunkSpec` variant; a `Project`'s
  `variables` become `InternedVal` while `args` stay verbatim.
- Assert the materialized flags match the fluent derivation: `intern(op).keepdims ==
  op.keepdims`, `intern(project).single == project.single`, `InternedRechunk.uniform ==
  rechunk.uniform`.
- Update `test_roundtrip_intern_schema_unchanged` for the `InternedVal` schema.

## Deferred (explicitly out of scope this round)

- **Running the optimiser over the interned form + equivalence property tests.** Now
  *possible* (structure preserved), but needs the optimiser decoupled from its `kwargs`
  string-literals (`Reduce.keepdims`, `_mergeable_select`'s `k in node.indexer for k in
  node.kwargs`) and either optimiser dispatch generalized to the `Interned*` types or a
  reuse of the fluent types. Best done when the Rust reasoner (or a Python validation of it)
  actually needs it; today's round-trip on optimised plans is the meaningful check.
- **Rust serialization of verbatim `args`/`kwargs`** (which may hold arrays). The intended
  shape: Rust reorders by handle and Python retains the replay headers side-band, so arrays
  never cross the boundary — a separate workstream.
